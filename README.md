# 🎬 Práctica Películas

Este proyecto, **Práctica Películas**, fue desarrollado con el objetivo de fortalecer mis conocimientos en desarrollo web, aplicando **HTML**, **CSS** y **JavaScript (DOM)**. A través de esta práctica, se construyó una página de películas interactiva que permite explorar y visualizar información de forma dinámica.

---

## 🧩 Descripción

El proyecto consiste en una página web dedicada a mostrar películas, donde se trabajó principalmente con la manipulación del **DOM (Document Object Model)** para generar contenido de manera dinámica.  
Durante el desarrollo se aplicaron principios de estructura semántica, diseño responsivo y estilos modernos con **CSS**, además de la interacción mediante **JavaScript** puro.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – para la estructura del sitio.  
- **CSS3** – para los estilos y diseño visual.  
- **JavaScript (DOM)** – para la interacción dinámica y manipulación de elementos.  

---

## 🎯 Objetivos de aprendizaje

Durante el desarrollo de este proyecto, aprendí a:

- Trabajar directamente con el **DOM** para crear, modificar y eliminar elementos dinámicamente.  
- Implementar **nuevos métodos y propiedades de CSS** para mejorar el diseño y la presentación.  
- Organizar el código JavaScript de manera más clara y eficiente.  
- Comprender mejor la interacción entre **HTML**, **CSS** y **JavaScript**.  
- Reforzar la importancia de la estructura y la semántica en el desarrollo web.
